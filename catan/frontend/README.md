# Frontend

Cliente web de Colonos de Catán con React 19, Vite, MUI y Bootstrap.

```bash
npm install
npm run dev      # servidor de desarrollo
npm test         # vitest
npm run lint
npm run build
```

El servidor se toma de `VITE_SERVER_URL` (por defecto `ws://localhost:2567`). Está desplegado en Vercel.

Más detalles de la estructura en el [README de catan](../README.md).
